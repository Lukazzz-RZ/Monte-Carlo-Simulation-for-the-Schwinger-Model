# Figures and data

This folder contains figures and numerical values used to illustrate the Schwinger-model thesis project in the main README.

## Figures

- [Topological-response heatmap](figures/topological_response_heatmap.svg): a compact view of the topological response as a function of the topological angle and four discrete fermion masses.
- [Topological-response curves](figures/topological_response.svg): an alternative line-plot view of the same data.

## Data

- [Topological-response data](data/topological_response_preview.csv): rounded values used to produce the overview figures.

The figures are based on thesis results for a 12 × 12 lattice at β = 14.4. They are illustrations of previously obtained data, not new runs of the current default program settings. Statistical uncertainties are not shown in these overview figures; consult the full thesis for their analysis and interpretation.
